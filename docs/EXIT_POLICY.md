# AI 出口策略与验证边界

配置唯一事实源为 `ai_line.exit_policy`，枚举 `locked/failover_only/adaptive`。固定模式另需明确的 `locked_node`，只按完整名称精确匹配，不按国家、模糊名称或“更快节点”认领。真实节点、地址、订阅与凭据只保留本地配置，不进入 Git 或示例。

## 执行与持久化

`exit_policy.py` 提供迁移、选择授权与证据状态。router 在固定策略决策入口和最终选择入口双重拒绝自动操作，连接清理也受固定策略保护。快检与完整检测共用该入口。仅故障备援只授权确认故障或移除；稳定性、慢速、恢复回优、手动保护到期和自动接管均不得绕过。

AI 候选发现从控制器叶子库存进行，独立于只有一个成员的服务组，不新增可见代理组。国家来自明确配置，不因外部选择漂移自动换国家。其他通用组按原方式工作。

`ai_line.group_definition` 以 regexp2 绝对锚点和转义完整名称匹配目标，空组显式 `REJECT`，保持 `interrupt-exist-connections: false`。缺席目标不作为静态必需引用，订阅移除后仍可加载原 AI 规则。Mihomo 最低版本为1.19.27；版本不足拒绝写入。

保存走预览→合并校验→当前目标复核→内核校验→备份→原子替换各文件→重载→成员核验→持久化，失败恢复原配置。文件系统不提供跨文件原子事务；运行内核只有校验后的整份配置被接受后才切换，失败回滚并明确报告错误。保存新策略移除旧开关，升级保留旧语义。关闭专线使用已有撤销路径恢复原分组与规则。

`configured_mode` 表示配置意图；`boundary_verified` 只表示 live 组、明确目标与已应用 AI 规则核实。`effective_mode=locked` 进一步要求新鲜快照里至少有一条已识别 AI 连接、全部与目标一致，且其他出口/未知均为0；它也不表示全流量或公网地区证明。设置和看板直接显示同一后端 `headline/summary/severity/evidence_detail`，使用“规则约束已核实/已识别 AI 连接一致”，不声称“全部固定已生效”。

`connections` 分别提供 target/foreign/unknown/unclassified/identified。Mihomo 链的首项必须是可核对的目标叶子，才算 target；同国其他节点、其他国家和 DIRECT 均为 foreign；缺链、仅分组链、链的叶子无法确认均为 unknown。foreign 或 unknown 任一非零时 `effective_mode=None`、汇总不绿；零活动显示 `no_sessions`、中性状态，不作为100%一致证据。普通连接无法识别 AI 归属时只计入 unclassified，不盲目判违规。健康会话自然结束，不为状态变绿强制清理。

`checked_at` 与 `connections.checked_at` 分别记录规则/组和连接证据时间，`expires_at` 取两者最早期限，有效期50秒。抓取失败、缺少响应字段与成功的空连接快照不同；Mihomo 明确返回 `connections:null` 视为成功的空快照。离线、失败、过期、未来时钟异常均不绿。完整检测保留连接实际采集时刻，快检刷新快照生成时间不续期连接证据；缓存 HTTP 读取只降级过期结论，不查询控制器/扫描连接。页面读取失败或证据到期只降级旧结论，不能保留旧绿色提示。

控制器离线不等于连接已经拒绝。外部客户端可改写运行配置；偏离约束应显示未核实/漂移，不承诺抵抗任意配置覆盖或路径绕行，也不保证供应商公网IP、NAT和实际地理位置。

## 现有连接与规则推演的口径

`inherited_connections` 兼容字段等于 foreign 数量；unknown 另在连接分类中列出。识别同时检查受管组、已应用规则与现有域名、IP、进程或已记录规则命中。旧组名称不参与模糊推断，旧规则集/旧分组的 Claude 会话可按域名识别；不依据开始时间断言它必然是旧会话。设置 API 与看板使用同一后端函数与已应用规则。

此计数是可观测范围内的核验：GEOSITE/ASN 无法仅凭任意 IP 推断，缺少元数据且旧规则命中不在应用规则中时无法归类；零条不是所有客户端流量均经固定出口的证明。“34/34”独立表示当前规则推演的通过项数，国家来自节点名称，不是 34 个客户端请求、实际公网 IP 或地理库验证。外部检测结果必须与新连接的时间和实际链一并判断，不能把截图上的某个 IP 与某条连接未经关联就认作同一次请求。

如需恢复，先等待旧会话自然结束并复测；不清 Cookie、不清所有连接。如确实需要中断单条会话，必须先核对当前 ID/主机/影响并取得确认，过期 ID 不可复用。

## 自动化验收

```
STEADYROUTE_MIHOMO=/path/to/mihomo STEADYROUTE_REQUIRE_CORE=1 ./scripts/check.sh
```

`test_exit_policy.py` 检查兼容、拒绝所有自动选择原因、候选检测保留、空集合与明确锁定校验。`test_real_core.py` 使用真实设置服务验证完整规则应用、重载、撤销和持久化失败回滚。`test_exit_policy_core.py` 使用另一个临时内核、本地HTTP转发叶子、独立客户端与可用备用/DIRECT控制路径，验证客户端链和端点命中；覆盖慢速、失败探测但业务可用、错误/超时、目标断开、改名/移除、空集、重载、控制器重连、隔离进程暂停恢复及重启。故意把配置改成备用和DIRECT的变异必须被真实命中识别。设置 `STEADYROUTE_EXIT_EVIDENCE` 可将合成链与命中记录保存到仓库外JSONL。

HTTP叶子仅用于测受管组/规则约束，不假冒用户供应商的Hysteria2传输或公网出口测试。SIGSTOP/CONT模拟进程暂停，不等同实际系统休眠；真实休眠与长期生产稳定性仍需专门观察，不以本地快速演练宣称全部通过。

## 管理验收与生产边界

开发不更换、重载或停止生产组。实际应用前重新只读核对当前选择是否仍是用户指定目标；不同则报告管理，不切回、不重选。旧72小时资料保留，新增后端专项验证与观察另行记录。发布/安装由管理按既有用户授权和核验结果执行；推送分支不等于合并或生产安装。
