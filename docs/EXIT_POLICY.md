# AI 出口策略与验证边界

配置唯一事实源为 `ai_line.exit_policy`，枚举 `locked/failover_only/adaptive`。固定模式另需明确的 `locked_node`，只按完整名称精确匹配，不按国家、模糊名称或“更快节点”认领。真实节点、地址、订阅与凭据只保留本地配置，不进入 Git 或示例。

## 执行与持久化

`exit_policy.py` 提供迁移、选择授权与证据状态。router 在固定策略决策入口和最终选择入口双重拒绝自动操作，连接清理也受固定策略保护。快检与完整检测共用该入口。仅故障备援只授权确认故障或移除；稳定性、慢速、恢复回优、手动保护到期和自动接管均不得绕过。

AI 候选发现从控制器叶子库存进行，独立于只有一个成员的服务组，不新增可见代理组。国家来自明确配置，不因外部选择漂移自动换国家。其他通用组按原方式工作。

`ai_line.group_definition` 以 regexp2 绝对锚点和转义完整名称匹配目标，空组显式 `REJECT`，保持 `interrupt-exist-connections: false`。缺席目标不作为静态必需引用，订阅移除后仍可加载原 AI 规则。Mihomo 最低版本为1.19.27；版本不足拒绝写入。

保存走预览→合并校验→当前目标复核→内核校验→备份→原子替换各文件→重载→成员核验→持久化，失败恢复原配置。文件系统不提供跨文件原子事务；运行内核只有校验后的整份配置被接受后才切换，失败回滚并明确报告错误。保存新策略移除旧开关，升级保留旧语义。关闭专线使用已有撤销路径恢复原分组与规则。

`configured_mode` 表示配置意图，`effective_mode` 仅在 live 组与受管 AI 规则核实后给出；`policy_status` 包括 locked/probe_abnormal/missing_reject/controller_offline/selection_drift/boundary_unverified。激活前若还有挂在其他出口的历史连接，显示 `inherited_sessions`，新连接已约束但暂不标全部固定生效；健康旧连接自然结束，不能为状态变绿强制清理。控制器离线是无法验证，不等于连接已经安全拒绝。其他客户端或外部配置能改写运行配置；偏离约束时应显示未核实/漂移，不能声称可抵抗任意外部配置覆盖或网络路径绕行。固定策略只约束受管 AI 分流，不能保证供应商公网IP、NAT和实际地理位置。

## 自动化验收

```
STEADYROUTE_MIHOMO=/path/to/mihomo STEADYROUTE_REQUIRE_CORE=1 ./scripts/check.sh
```

`test_exit_policy.py` 检查兼容、拒绝所有自动选择原因、候选检测保留、空集合与明确锁定校验。`test_real_core.py` 使用真实设置服务验证完整规则应用、重载、撤销和持久化失败回滚。`test_exit_policy_core.py` 使用另一个临时内核、本地HTTP转发叶子、独立客户端与可用备用/DIRECT控制路径，验证客户端链和端点命中；覆盖慢速、失败探测但业务可用、错误/超时、目标断开、改名/移除、空集、重载、控制器重连、隔离进程暂停恢复及重启。故意把配置改成备用和DIRECT的变异必须被真实命中识别。设置 `STEADYROUTE_EXIT_EVIDENCE` 可将合成链与命中记录保存到仓库外JSONL。

HTTP叶子仅用于测受管组/规则约束，不假冒用户供应商的Hysteria2传输或公网出口测试。SIGSTOP/CONT模拟进程暂停，不等同实际系统休眠；真实休眠与长期生产稳定性仍需专门观察，不以本地快速演练宣称全部通过。

## 管理验收与生产边界

开发不更换、重载或停止生产组。实际应用前重新只读核对当前选择是否仍是用户指定目标；不同则报告管理，不切回、不重选。旧72小时资料保留，新增后端专项验证与观察另行记录。发布/安装由管理按既有用户授权和核验结果执行；推送分支不等于合并或生产安装。
