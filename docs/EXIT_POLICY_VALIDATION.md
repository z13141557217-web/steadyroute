隔离设置预览的设置、说明、日志页面与设置/看板 API 均返回 200，规则推演文案和固定状态正确；三个页面脚本语法检查通过。本修复未做浏览器视觉截图验收，不将 HTTP 检查当作视觉验证。rc.2 尚未发布或安装，远端 CI 以 PR 最终提交记录为准。

## 证据范围与待管理验收

上述演练证明受管组与规则的TCP客户端边界，HTTP转发叶子用于隔离传输，不冒充用户Hysteria2供应商、公网出口或实际地理位置测试。未让用户机器真实休眠；SIGSTOP/CONT和时钟间隙分支属于恢复模拟。未完成新后端的长期生产观察，也不以旧72小时资料证明本策略长期稳定。

外部客户端可以自行覆盖配置，定期核对会报告漂移/未核实；不承诺能抵抗任意外部配置覆盖或网络绕行。未对所有屏幕阅读器、缩放与浏览器组合做认证。
