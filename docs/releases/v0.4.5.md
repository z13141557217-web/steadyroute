## 看板重新设计，新增三个页面

### 看板
- 顶部状态面板：动态稳航图标（正常蓝 / 留意橙 / 故障红）、两条线路延迟、24 小时切换（故障 / 回优）、内存、累计检测。1512×982 下首屏可见节点表前三行。
- 两张线路卡片逐行对齐；统计项在窄卡片上仍保持一行。
- 延迟曲线可看 5 / 15 / 30 分钟，平滑滚动；热备画为虚线；故障切换红色实线、无损回优绿色虚线；悬停或点按看数值。
- 活跃连接侧边面板：按节点、按网站查看，回优交接期间旧节点上的连接单独标出；只显示域名。
- 每个指标旁的“?”说明，可跳到使用说明对应章节。指标改名：近 24 小时可用率、平均延迟、综合评分。

### 新页面（均为只读，不加载外部资源）
- **全部节点** `/nodes`：订阅中的全部节点按地区分组，显示 Clash 自己的测速，标出当前在用 / 热备 / 候选 / 仅查看。选路逻辑不变，“仅查看”的节点永远不会被选中。
- **使用说明** `/guide`：14 节，文中数值从运行中的服务读取。选路规则从看板移到这里。
- **更新日志** `/changelog`。
- 新增只读接口 `GET /api/nodes`，每轮检测结束时生成一次。

### 修复
- 较新的 macOS 上读取内存峰值失败的问题，现在直接读取系统记录的峰值。

### 兼容性
- 状态与 API schema 仍为 2，只追加字段；新增文件 `node_catalog.py`、`nodes.html`、`guide.html`、`changelog.html`、`pages.css` 已纳入部署清单。

### 部署

```bash
git checkout v0.4.5
./scripts/build-release.sh
./scripts/deploy-local.sh          # 预演
./scripts/deploy-local.sh --apply
```

也可以直接下载下方的 `steadyroute-0.4.5.zip` 和校验文件。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.4.5/CHANGELOG.md)。
