# v0.6.2-rc.4 节点表界面候选

安装包名为 SteadyRoute-v0.6.2-rc.4.zip。

节点主表保留名称、近期可用率、长期可用率、最近检测和选路状态。
历史检测说明、抖动、评分、连续次数放入可展开详情。

- 名称最多两行，固定列宽，不受长历史说明挤压。
- 地区与关注范围独立筛选，显式排序立即生效，阅读期间保持行序。
- 详情刷新时保持展开，键盘焦点保持；窄容器显示紧凑节点列表。
- 检测成功与恢复验证可以同时显示，前端不推导选路资格。

候选需页面验收后另行安装。当前rc.3观察不因开发而重置或修改。
不修改选路阈值、探测频率和后端数据契约。普通降级重新安装旧版本安装包。
