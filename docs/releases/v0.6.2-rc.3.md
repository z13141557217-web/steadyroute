# v0.6.2-rc.3 图表与节点状态候选

安装包为 SteadyRoute-v0.6.2-rc.3.zip。

- 当前曲线采用统一快检来源，5秒汇总成功、失败和等待，显示延迟范围及独立状态条。
- 线段使用直线，遇到失败、空档或换节点断开。热备同样处理。
- 可固定纵轴，超出范围时显示标记。
- 节点按近期可用率排序，可切换长期可用率、延迟和角色排序。阅读时暂缓重排。
- 最新检测区分超时、错误、检测不可用和过期，另列历史成功值，暂停与恢复进度继续保留。

这是预发布候选，真实环境验收仍待完成。开发记录见 ../../CHANGELOG.md。

## 验证与边界

- 完整检查通过，479 项测试，1 项平台条件跳过；包含隔离 Mihomo 内核演练。
- 模拟页面验证排序、Timeout/Error 与最后成功值分开、固定纵轴和独立状态条。
- 不增加节点测速请求，探测延迟返回接口与选路阈值保持兼容。
- 旧检测记录无法追溯错误原因时显示未知；Mihomo 明确报告超时时才分类为 Timeout。
- 本包尚未安装到观察环境，不能作为真实环境或客户端恢复验收结论。

## 安装与回退

候选安装需要单独验收并记录新的观察区间。常规降级需重新安装上一候选或 v0.6.1 的安装包；
rollback.command 用于恢复迁移前的旧 LaunchAgent，不承担候选版本之间的降级。
