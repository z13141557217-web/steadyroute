## 安全加固

### 安全
- **防 DNS rebinding**：看板只服务 Host 为 `127.0.0.1:17654` 或 `localhost:17654` 的请求，其他一律返回 421。此前任何 Host 都能拿到完整数据，恶意网页可以借此读取你正在访问的网站和进程名。
- **所有响应带安全头**：主看板此前没有任何安全头。现在页面和接口经同一个出口，统一带 CSP（含 `frame-ancestors 'none'`，不能被嵌进别的网页）、`nosniff`、`no-referrer`、`no-store`。
- **密钥扫描不会被跳过**：改为纯标准库的 `scripts/leak-scan.py`。旧版在没装 ripgrep 的机器上会静默通过。

### 修复
- 三种切换（故障切换、无损回优、当前节点从订阅消失）由同一个函数记录。“节点消失”的切换此前不计数，现在显示为“节点移除”。
- 切换历史保留最近 24 小时，一天超过 10 次时不再少算。

### 改进
- 生产和日志目录跟随当前用户，可用 `STEADYROUTE_BASE_DIR`、`STEADYROUTE_LOG_DIR` 覆盖。
- 全量测试从约 22 秒降到约 7 秒；CI 覆盖 macOS（Python 3.9）和 Ubuntu（Python 3.9、3.13）。
- 选路行为与 v0.4.5 完全一致（6 个模拟场景对比）。状态文件只新增一个字段，可直接回滚。

### 部署

```bash
git checkout v0.4.6
./scripts/build-release.sh
./scripts/deploy-local.sh          # 预演
./scripts/deploy-local.sh --apply
```

部署后 `curl -H "Host: evil.example:17654" http://127.0.0.1:17654/api/status` 应返回 421。

也可以直接下载下方的 `steadyroute-0.4.6.zip` 和校验文件。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.4.6/CHANGELOG.md)。
