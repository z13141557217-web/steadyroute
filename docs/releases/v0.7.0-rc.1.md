# v0.7.0-rc.1 AI 固定出口策略候选

候选安装包名为 SteadyRoute-v0.7.0-rc.1.zip。本开发候选未合并、未发布 Tag/Release、未安装生产，不替换 Latest。发布阶段由管理对话核验对应提交、Tag、候选 Release、安装包及校验文件。

三种互斥策略为固定节点、仅故障备援与自动择优。固定模式在后台选择入口拒绝所有自动更换，内核组只匹配明确叶子目标，消失或改名后保持 AI 规则并 REJECT。候选检测继续；单纯探测失败不主动清理健康会话；固定前仍在其他出口的历史连接自然结束前，不标全部固定生效。

仅故障备援不因慢速或稳定性择优换节点；确认故障或移除时可换同国家备用，恢复后不自动返回。自动择优保留旧能力。两者在设置页均有红色图标及“可能改变出口IP，存在账号风控风险”。固定节点也不保证供应商动态公网IP不变。

旧 slow_exit=false 仍为仅故障备援，true/缺省保留旧行为。保存新枚举移除旧开关；当前选择发生变化时拒绝悄悄重选。已保存策略与实际约束证据分别展示，离线、漂移与未核实时不可标为固定生效。

专项验证使用独立 Mihomo、临时端口/socket、本地转发代理与独立客户端；备用与DIRECT保持可用，通过真实链与命中记录验证防回退，并用故意错误配置证明测试能检测回退。详见 [出口策略与验收边界](../EXIT_POLICY.md)。此证据不证明供应商IP及地理位置永不变化，隔离进程暂停/重启也不代替真实机器休眠长期观察。

本次改变后端执行策略，rc.4 的72小时观察资料保持原样，不能套用旧结论。生产应用前再次只读核对用户当前选择；如已变化，交管理核对，不擅自切回。

回滚：未部署时撤回候选即可。获授权部署后，先按设置关闭/撤销受管专线或恢复配置备份，再使用上一安装包/安装器回滚；明确告知回滚到rc.4将失去严格固定能力，不能继续显示固定生效。
