## 分享版：装在朋友的 Mac 上也能用

### 新增
- **按国家锁定，只换这个国家的家宽**：装在朋友的 Mac 上时，稳航接管他 Clash Verge 里直接选中了节点的分组。选的是美国节点就锁美国，之后只在美国家宽之间切换，不会跨国家，也不改他的 Clash 配置。
- **手动换国家会跟着改锁**：朋友在 Clash 里切到日本节点，稳航改锁日本。
- **普通节点换上家宽**：当前是同国家普通节点时，家宽预热好（约 1 分钟）后无损换过去；之后手动选普通节点保留 60 分钟，断了立刻换。
- **没有家宽就不动**：没有家宽的国家只提示；分组选的是“自动选择”这类分组时暂停。
- **一键安装包**：Release 里的 `SteadyRoute-share-v0.5.0.zip` 发给朋友，解压后右键 `install.command` → 打开。升级再运行一次，失败自动恢复上一版；`uninstall.command` 卸载。打包时自动检查，不带你的配置、节点名、路径等个人信息。

- **刚装好约 1 分钟就有保护**：预热时顺带多测几个家宽节点，约 45 秒就有可用的备用节点（原来约 4 分钟）。
- **曲线标出你自己的手动切换**：灰色虚线“你手动切换”，和故障切换、回优分开，不计入切换次数。

### 修复
- **重启不再显示成休眠**：稳航看 macOS 记下的开机、入睡、唤醒时间，分清“Mac 刚开机”“刚从休眠恢复”“稳航重启过（停了 N 秒）”。部署或自动重启不再白白暂停一轮判断。
- 休眠时长显示整段休眠（合并 Power Nap 等短暂唤醒），并注明期间短暂唤醒几次。
- 快速故障切换后看板立即显示新节点，不再等最多 20 秒。

### 你自己的这台 Mac
部署成功后只保留最近 10 份备份（刚被替换的上一版总在其中）。
作者版（台湾 / 香港固定配置）选路行为不变。

```bash
git checkout v0.5.0
./scripts/build-release.sh
./scripts/deploy-local.sh          # 预演
./scripts/deploy-local.sh --apply
./scripts/publish-release.sh       # 发布 Release，并附上分享包
```

也可以直接下载下方的 `steadyroute-0.5.0.zip`（作者版）和校验文件。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.5.0/CHANGELOG.md)。
