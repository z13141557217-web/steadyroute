## 修复：Clash Verge 服务模式下专线无法写入

### 修复
- **“升级这些线路”与开启 AI 专线报“没有生效”**：Clash Verge 以服务模式运行时，Clash 内核只接受它自己目录下的配置文件，v0.5.1 让它从用户目录的文件重新加载，被拒绝（HTTP 400，`path is not subpath of home directory or SAFE_PATHS`）。v0.5.1 遇到这个错误时会把文件恢复原样，Clash 一直按原配置运行，没有造成改动。现在稳航把配置内容直接交给内核加载，不再依赖文件所在位置。
- 安装完成时不再误报“还没连上 Clash Verge”：安装器会等稳航与 Clash 完成第一次连接，再显示接管的线路。

### 变化
- **写入前多一项核对**：Clash 正在运行的分组必须和运行配置文件一致，否则不做任何改动，并提示在 Clash Verge 里重新选中当前订阅后再试。
- **失败提示更准确**：Clash 拒绝新配置时，它仍按原配置运行，稳航只把文件恢复原样，不需要其他操作。

### 升级

已安装 v0.5.1 的：

```bash
git pull
./install.command
```

或下载下方的 `SteadyRoute-v0.5.2.zip`，解压后右键 `install.command` → 打开。设置和线路保持不变；装好后在设置页点“升级这些线路”即可。想回到升级前的版本运行 `rollback.command`。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.5.2/CHANGELOG.md)。
