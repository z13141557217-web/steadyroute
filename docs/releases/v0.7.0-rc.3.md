# v0.7.0-rc.3 总开关候选

候选安装包 SteadyRoute-v0.7.0-rc.3.zip，基于已发布 rc.2，另纳入 PR #48 的按订阅隔离撤销记录修复。未合并、未安装生产；不覆盖 rc.2 Tag，不替换稳定 Latest。Tag、GitHub Release 与公开包发布另由管理验收授权，本次只提供本地候选包和校验。

总开关区分已保存意愿、工作进程和轻量控制页面。暂停先持久保存保持停用，关闭新操作入口，等待已接纳的事务（含回滚）及探测请求完成，再退出工作进程。晚到回调不能重新提交；屏障或进程退出失败显示未完成。停止后的控制页面不会检测、选路、同步规则或修复配置；原固定规则可能仍在，不把暂停说成撤销。

“停用并交还 Clash”预览当前订阅自己拥有的分组和规则，明确确认撤销固定出口保护后才操作。保留原偏好、目标、历史和其他订阅恢复记录。内核校验、备份、失败恢复继续生效；归属记录不可信时拒绝猜测。保留存活的原生选择，不清连接或 Cookie。

独立启动/停止 .command 在安装包顶层和安装目录均提供。启动入口重新打开控制页面，用户预览并确认后启动工作进程；停止入口先完成暂停，再退出控制页面并卸载本次 launchd 注册。登录时启动工作进程单独保存；已暂停不会因 KeepAlive、重新登录或重启而恢复接管。控制页面可在登录时保留，但不代表工作进程运行。进程崩溃不自动重启工作任务；控制器异常重启进入停用，原子事务与归属仍需核对。

启动核对当前订阅源、实际内核、保存目标和预览指纹。缺少原目标、外部选择漂移、离线或预览变更均阻断，不选择其他国家或 DIRECT。暂停时可明确预览并保存下次启动目标；候选清单来自当前订阅与内核交集，不默认选中。此操作仅保存偏好，仍保持停用，再启动需重新核对。

当前连接证据与历史缓存不混用。停止页不显示旧绿色检测结果；继续保留旧数据和观察区段，不重置既有长期观察。此版本改变后端进程和配置管理，需要独立候选验收；不借用原观察结论。

订阅 Timeout 的真实本机诊断保留在本地交付资料，不含在公共仓库。本版本不承诺修复所有节点的网络超时；保存失败、缺锁定目标与协议连通性分别验证。旧版污染记录仍需根据备份恢复，详见 [恢复说明](../PROFILE_RECOVERY.md)。回滚时程序、控制状态、配置与应用记录成套恢复；旧版不理解新的停止意愿和多订阅账本。

候选验收发现macOS默认HTTP服务初始化会等待本机地址反向解析，导致页面延迟就绪。控制服务改为直接使用localhost名称，保持本机监听与Host防护；反向解析阻断回归和独立真实启动冒烟覆盖此路径，不以延长超时替代修复。同一rc.3候选继续迭代。

视觉及独立入口补充：固定策略的AI分组明确显示“固定策略”，不再把它计入自动切换开启数；总开关运行状态描述工作进程，避免与线路健康混淆。撤销确认错误持续保留到下一次操作，不被轮询清掉。独立启动/停止读取同一安装目录登记的实例、端口与启动项，避免隔离验收或副本操作误指向其他实例。实例记录为本地运行资料，不随包或Git分发。

独立停止入口在页面离线时也会核对并卸载本实例的KeepAlive启动项；只有工作进程、控制页面和启动项均核实停止后才报告完整退出。

键盘操作：预览加载后焦点进入预览区域，Tab依次到确认控件；未勾选撤销确认时报错并聚焦确认框，取消后回到发起按钮。
