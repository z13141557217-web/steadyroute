## 诊断信息；看板文字更准确

### 新增
- **复制诊断信息**：设置页“高级信息”里新增一个按钮，把一份文本报告放进剪贴板，可直接粘贴发送。内容包括版本与系统、专线与运行核对、各线路状态、近 7 天的切换记录（带切换前的探测值，并标出唤醒或启动后不久发生的故障切换）、休眠与服务启动记录、节点健康数据。不含订阅地址、服务器地址、密码和访问过的网站；本机路径与 IP 地址已遮盖。稳航不向任何地方发送这份内容。

### 修复
- **AI 专线不再显示“回优”**：专线只在节点故障时切换，但故障切换之后看板显示的是“刚完成回优”“处于性能冷却期”。现在正常时显示“当前节点正常，专线保持出口不变”。切换逻辑没有变化，只是文字。
- 延迟曲线上靠近左边缘的切换标签不再被裁成一小段圆角。
- “全部节点”页不再把 Clash 内置的 `PASS-RULE` 当作节点。
- Clash 内核缺少某个数据库时，只跳过它指出的那条规则（此前可能多跳过一条），失败提示里显示内核给出的原因。

后两项是在真实 Clash 内核上运行测试时发现的。

### 升级

```bash
git pull
./install.command
```

或下载下方的 `SteadyRoute-v0.5.4.zip`，解压后右键 `install.command` → 打开。设置和线路保持不变，不需要重新确认写入。想回到升级前的版本运行 `rollback.command`。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.5.4/CHANGELOG.md)。
