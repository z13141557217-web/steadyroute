# v0.7.0-rc.2：AI 旧出口连接核验修复候选

当 AI 规则重新应用后，已有连接可以继续使用原来的规则与出口。rc.1 只统计经过新 AI 分组的连接，旧分组中的 Claude 会话可能漏报为零。rc.2 使用已应用 AI 规则与连接元数据补报这些会话，设置和看板在它们结束前保持未全部固定状态，不主动清理健康连接。

设置页的“34/34”改为明确的规则推演文案：这是按当前规则与节点选择计算的通过项数，国家取自节点名称，不是实际请求或公网 IP 地区检测。元数据不足的连接无法完整归类，零条不等于全部流量已验证。

验证包括设置快照回归、域名边界及无关流量反例，以及隔离真实 Mihomo 的旧规则集/旧分组长连接跨重载场景；新请求走指定目标，旧连接保留到自然结束，之后状态恢复。

本版本包含后端核验变化，是独立候选，尚未授权发布或安装；既有生产观察资料保留。候选包名为 `SteadyRoute-v0.7.0-rc.2.zip`，仅在发布获授权后生成并核对安装包、校验文件、Tag 与预发布 Release，不替换稳定 Latest。
