# v0.7.0-rc.2：AI 旧出口连接核验修复候选

当 AI 规则重新应用后，已有连接可以继续使用原来的规则与出口。rc.1 只统计经过新 AI 分组的连接，旧分组中的 Claude 会话可能漏报为零。rc.2 分层核对配置、规则/组、已识别 AI 连接、新鲜度与覆盖范围，设置和看板读取同一后端结论，不主动清理健康连接。

已识别连接分别计入目标一致、其他出口、路径未知；同国异节点、其他国家与 DIRECT 均为其他出口，缺链或仅分组链为未知。其他出口或未知任一存在，汇总不显示绿色一致；零活动仅显示暂无可识别会话证据。控制器离线、抓取失败、证据过期和页面读取失败不保留旧绿色提示，快检不会刷新旧连接证据年龄。规则与连接快照各带时间，有效期50秒；无法识别归属的普通连接不判 AI 违规。

设置页的“34/34”改为明确的规则推演文案：这是按当前规则与节点选择计算的通过项数，国家取自节点名称，不是实际请求或公网 IP 地区检测。元数据不足的连接无法完整归类，零条不等于全部流量已验证。

验证包括设置/看板一致性、混合分类、抓取失败、过期与快检不续期、域名边界及无关流量反例；隔离真实 Mihomo 检查旧规则集/旧分组、同国异节点、其他国家、DIRECT长连接跨重载，以及目标异常/断开/消失时拒绝而不回退。旧连接自然结束后只显示规则已核实/暂无会话证据，不冒充实际连接全量固定。独立预览提供合成场景切换，测试类型与限制详见验证文档。

本版本包含后端核验变化，按候选流程发布，不替换稳定 Latest。发布管理先按验收表逐项核对最终提交、测试和未覆盖边界，验收通过后再按条件授权发布并安装；安装结果以部署记录为准，本文不预先宣告生产验收通过。候选包名为 `SteadyRoute-v0.7.0-rc.2.zip`，发布时同步核对精确 Tag、预发布 Release、安装包和校验文件，保留原台湾锁定目标及既有观察记录。
