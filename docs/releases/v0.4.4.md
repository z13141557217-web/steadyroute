## 日志不再无限增长

### 修复
- **有界日志**：`router.log`（14 天）、`events.jsonl`（90 天）、`node-events.jsonl`（30 天）、`router-error.log`（30 天），按天和大小轮换、gzip 压缩，合计不超过约 38 MB。升级时旧的无界日志一次性压缩保留 90 天。
- 最快的节点不再因为一次偶发丢包被隔离并强制切走：被同一轮其他探测否定的失败只计入可用率。
- 修复回优与故障恢复同时发生时，一轮检测的切换记录可能丢失的问题（v0.3.0 起存在，由压力模拟发现）。
- 浏览器关闭页面不再产生 traceback；看板服务改为多线程。

### 新增
- 内存显示“当前（峰值）”，`status.sh` 给出每小时内存趋势；看板显示上次休眠恢复时间。
- “重点”筛选改名“需关注”；页面每 2 秒刷新。

### 部署

```bash
git checkout v0.4.4
./scripts/build-release.sh
./scripts/deploy-local.sh          # 预演
./scripts/deploy-local.sh --apply
```
