## 一个产品，一种安装方式；可选 AI 家宽专线

### 新增
- **AI 家宽专线（可选）**：在设置页选一个国家，稳航在 Clash Verge 里建立只含该国家家宽节点的专线，ChatGPT、Claude 等 AI 服务的规则排在所有规则之前。节点全部不可用时拒绝连接，不会改走直连或其他国家。完全按 ip.net.coffee：规则原样采用并排在最前，UDP 与 NTP 同样经专线出口；专线只在节点故障时切换，出口 IP 尽量不变。需要 Clash Verge 内核 mihomo v1.19.27 或更新。
- **AI 规则自动汇总**：以 ip.net.coffee 的 Claude 与 ChatGPT / Codex 分流规则为第一优先级（含 Anthropic IP 段与 ASN），其后是社区 AI 合集、AI 桌面 App、手动添加的域名。每周自动同步并更新地理数据库；同步异常时继续使用现有规则，并在 6 小时后重试。
- **写入安全**：写入 Clash 前列出分组成员与规则差异，确认后才生效；写入前由 Clash 内核校验并自动备份，任一步失败即恢复原配置。关闭专线或卸载会完整撤销，更新订阅不会丢失。
- **设置页**：三块可选设置，依次是 AI 出口国家、其他网站、自动切换的分组。开启专线后自动做 **AI 分流体检**，按 Clash 当前规则核对每个 AI 地址的去向与出口国家。
- 看板上的 AI 专线分组带“AI 专线”标记和“检测出口 IP”链接。

### 变化
- **只有一个版本**：不再区分分享版与自用版。新装、升级、换电脑都运行 `install.command`，仓库和发布包布局相同。
- **旧版自动迁移**：安装时自动识别旧版稳航，带过状态、节点历史和日志；新服务确认正常后才停用旧版，失败则恢复旧版。原来的台湾 / 香港线路会出现在设置页的“检测到旧版的线路”提示中，选择“升级这些线路”后改为同名、自动筛选同国家家宽的专线，Clash 中引用这些分组的规则继续有效。
- 新安装默认自动切换所有直接选中节点的分组；从旧版升级时只切换旧版原本切换的两条线路，其他分组保持原样，需在设置页自己开启。

### 安装 / 升级

下载下方的 `SteadyRoute-v0.5.1.zip`，解压后右键 `install.command` → 打开。已有仓库时：

```bash
git pull
./install.command
```

卸载运行 `uninstall.command`，稳航写进 Clash 的专线和规则会一并撤销。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.5.1/CHANGELOG.md)。
