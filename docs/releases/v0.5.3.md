## 运行核对：专线被覆盖后自动恢复

### 新增
- **每 20 秒核对 Clash 实际在运行的内容**：稳航写入的分组和 AI 规则必须都在 Clash 内核里。此前只有每小时一次，而且看的是配置文件；Clash Verge 用它内存里的旧配置重新加载时，文件没变、内核却不再运行专线，最长一小时内 AI 流量会按旧规则分流。现在专线不在时，稳航在下一次核对时重新写入，最迟 40 秒恢复。
- **未生效时看得见**：设置页“AI 出口国家”显示“未生效”、缺少的内容，以及正在重新写入或失败的原因；看板上的标记变为“AI 专线未生效”。高级信息新增“运行核对”一行，显示最近一次自动重新写入的时间。

### 安全
- 连续两次核对不符才重新写入，避免在 Clash Verge 重载途中误判。
- 重新写入失败时按 1、2、4 … 30 分钟延长间隔；Clash 接受了配置但专线仍然不在时停止自动写入；一小时内最多 6 次。不会反复重载 Clash。
- Clash Verge 没有运行时不算缺失，不做任何操作。

### 变化
- 设置页的“已生效”以 Clash 实际运行的内容为准，不再只表示“写入过”。

### 升级

```bash
git pull
./install.command
```

或下载下方的 `SteadyRoute-v0.5.3.zip`，解压后右键 `install.command` → 打开。设置和线路保持不变，不需要重新确认写入。想回到升级前的版本运行 `rollback.command`。完整开发记录见 [CHANGELOG.md](https://github.com/z13141557217-web/steadyroute/blob/v0.5.3/CHANGELOG.md)。
