# 产品待办与优先级

更新时间：2026-09-19

## MoSCoW

### Must

- 仓库成为唯一源码，禁止直接在生产目录常规开发。
- 自动部署前备份、校验、健康检查和失败回滚。
- 动态识别新增、改名和消失的家宽节点。
- 空候选 fail-closed，禁止 DIRECT 泄漏。
- 日志轮换和重复日志限频。
- 状态 schema version、迁移和损坏恢复。
- 后端决策状态码作为看板唯一事实源。
- 生产发布必须对应 commit、版本和校验和。

### Should

- 假 Mihomo Unix Socket 集成测试。
- 结构化事件和有界趋势数据。
- 浏览器主动断开回归测试。
- 自动睡眠恢复和控制器重连验证。
- 备份保留策略与恢复演练。
- 性能基线自动比较。

### Could

- 配置私有远程 Git 仓库。
- 发布报告自动生成。
- 看板导出脱敏诊断摘要。
- 本地通知关键故障。

### Won't Now

- 公网远程看板。
- 云数据库和远程控制面。
- 网页端强制切换节点。
- 自动购买或修改第三方订阅。

## 进入开发的条件

每项待办在进入开发前必须具备：

- 明确用户问题和成功指标。
- In Scope / Out of Scope。
- 可执行验收条件。
- 依赖、风险和回滚方式。
- 对版本号的影响。
