# ADR-0003：本地发布使用完整目录原子切换

> 已被 v0.5.1 取代（见 [ADR-0008](0008-unified-install-and-ai-line.md)）。

状态：Accepted  
日期：2026-09-19

## 决策

发布包使用外层 SHA-256 和逐文件清单验证。部署在生产目录同一文件系统准备完整目标，
保留运行状态等未纳入 Git 的文件，再以目录重命名完成切换。LaunchAgent plist 使用
同目录临时文件和 `os.replace` 原子替换。

## 原因

逐文件覆盖可能在中途留下混合版本。完整目录切换让所有受管文件同时来自同一发布包，
并保留可立即恢复的切换前目录。显式 `--apply` 与首次生产交互确认限制误操作范围。

## 后果

- 目标目录与暂存目录必须位于同一文件系统。
- 部署前停止 LaunchAgent，成功或恢复后重新启动并执行相同冒烟检查。
- 每次真实部署需要足够空间同时容纳暂存目录、完整备份和失败诊断目录。
- 回滚只接受 SHA-256 完整验证通过的完整备份。
