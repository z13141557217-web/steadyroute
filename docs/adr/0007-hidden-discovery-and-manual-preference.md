# ADR 0007：隐藏内部发现组与人工偏好保护

> 隐藏发现组部分已被 v0.5.1 取代（见 [ADR-0008](0008-unified-install-and-ai-line.md)）；人工偏好保护（现称“手动选择保护”）仍然有效。

## 状态

已接受，v0.4.2。

## 决策

动态候选继续使用 Mihomo 原生 discovery group，但统一设置 `hidden: true`。Mihomo 仍在
`/proxies` 返回该组的 `hidden`、`all` 和 `now`，SteadyRoute 可以读取候选；Clash Verge
Rev 2.5.4 前端按 `group.hidden` 过滤用户代理页，因此不再暴露重复组。若目标前端不适配
该 API 字段，则停止发布并改用不创建 UI 组的原始代理扫描，不能接受重复展示。

兼容状态码 `manual_hold` 改称“人工偏好保护”，最长 60 分钟。保护期只阻止健康线路的
性能回优；基础/业务检测、隔离、当前节点消失和真实故障切换始终运行。故障决策优先于
人工偏好，并在执行安全备援时清除偏好。旧状态中过长的剩余时间在运行周期中封顶。

## 后果

- 用户只看到正式台湾和香港组。
- 人工选择具有可预期的期限，同时不牺牲故障安全。
- API schema 保持 v2，旧客户端仍可识别 `manual_hold`，新版客户端读取 `automation`。
