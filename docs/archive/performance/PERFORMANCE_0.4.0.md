# v0.4.0 动态候选影子性能对比

日期：2026-09-20  
平台：macOS 系统 Python 3.9  
基线：已发布 `v0.3.0` / `60ea623`

## 方法

从 `v0.3.0` tag 解包到临时目录，与当前 worktree 分别在独立 Python 进程中导入。
两边使用空状态、预生成缓存和本机回环随机端口；每项运行三次并取中位数。测量一次 GET、
空闲一秒进程 CPU、100 次串行 GET、峰值 RSS 和紧凑 JSON 状态大小。没有读取 Mihomo、
生产状态或真实配置，也没有修改或部署生产。

## 结果

| 指标 | v0.3.0 | v0.4.0 shadow | 差异 |
|---|---:|---:|---:|
| 峰值 RSS | 19.141 MB | 19.250 MB | +0.109 MB |
| 空闲 CPU | 0.0162% | 0.0198% | +0.0036 个百分点 |
| 单次兼容 API | 4.423 ms | 3.649 ms | -0.774 ms |
| 100 次兼容 API | 19.650 ms | 19.126 ms | -0.524 ms |
| 兼容 API 100 次平均 | 0.196 ms | 0.191 ms | -0.005 ms |
| 单次 `/api/v1/status` | 0.192 ms | 0.181 ms | -0.011 ms |
| 100 次 `/api/v1/status` | 18.121 ms | 17.111 ms | -1.010 ms |
| 新 API 响应 | 3,235 bytes | 5,014 bytes | +1,779 bytes |
| 空状态 | 393 bytes | 1,124 bytes | +731 bytes |

已确认 16 个当前策略节点的影子注册表状态为 14,590 bytes。退役记录 24 小时后清理，
事件仍限制为 200 条，因此状态有时间和数量上限。

## 结论与激活门禁

RSS 增量为 +0.109 MB，低于 ≤1 MB 目标；空闲 CPU 仍接近 0%，缓存 API 无明显回退。
`config/route-policies.json` 记录实测增量 0.11 MB，但 `activation.approved=false`，因此
正式接管仍被阻止。若后续实机影子观察超过预算，应保留 shadow 并回滚到 v0.3.0，
不得激活动态选路。
