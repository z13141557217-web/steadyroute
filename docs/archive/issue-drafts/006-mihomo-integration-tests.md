## 用户问题

现有测试主要覆盖纯决策函数，尚未验证 Unix Socket HTTP、控制器超时、连接关闭、动态候选和配置重载等真实边界。

## 范围

- 假 Mihomo Unix Socket 控制器。
- `/proxies`、`/connections`、delay、选择和关闭连接协议。
- 超时、chunked 响应、HTTP 错误和畸形 JSON。
- dry-run 全周期和睡眠恢复场景。

## 验收条件

- [ ] 测试不依赖真实订阅或外网。
- [ ] 覆盖成功、超时、断线、4xx/5xx 和畸形响应。
- [ ] 验证普通回优不关闭健康旧连接。
- [ ] 验证真实故障只关闭旧节点连接。
- [ ] 验证控制器恢复后自动继续。
- [ ] CI 可稳定重复运行且无随机失败。

## 风险与回滚

测试夹具不得接触真实 socket 或生产目录。所有路径、时间和随机性必须可注入。
