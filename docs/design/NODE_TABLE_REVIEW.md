## Direction contract

THESIS：让用户快速识别当前线路和异常候选，删除重复图形负担。
OWN-WORLD：沿用白/深蓝中性背景和海蓝强调；系统中文字体、对齐数字、细分隔、轻量箭头。
STORY：先认节点角色，再比较近期/长期可靠性，最后查看最新检测与选路状态，按需展开依据。
FIRST VIEWPORT：节点标题和数量同一基线，筛选栏紧凑；表头与内容严格对齐，64px主行展示更多节点。
FORM：操作型数据清单；候选A紧凑监控，B舒适清单；seed: none (unavailable)。
FINISH：以桌面与窄屏、明暗主题、键盘和实际内容渲染完成检查，记录结论和限制后交付预览。
