# 检测规则与探测范围

本功能属于 v0.7.0-rc.3 未发布候选，开发基线为总开关分支；不代表已合并、已安装生产或已获得发布授权。VERSION 保持同一候选身份。

## 使用

1. 仅本机授权文件中精确匹配的订阅可使用本功能；缺少文件、非授权 UID 或同名重新导入的新 UID 均不接管。新安装默认没有探测授权。启动工作进程后，在设置中勾选明确的叶子节点并保存；快检、全检、业务、预热、复测及切换前检查共用此选择。只有订阅中可见、属于候选或被称为热备，不会使节点自动获得授权。
2. 导入检测规则前，核对当前 AI 专线是固定节点策略，分组只有明确的叶子节点且当前选择一致。设置中预览并导入当前订阅；缺失、漂移、订阅源不含目标、预览后配置变化或校验失败时阻断，未选另一节点。
3. 内置条件为 `2026.ip138.com`、`my.ip.cn`、`1.1.1.1/32` 且目的端口 443、`claude.ai`、`www.anthropic.com`。目标从用户当前固定设置生成，不随程序分发真实节点或分组名。已有 Claude 的正确后缀规则覆盖精确条件时复用，不重复增加。
4. 导入后授权订阅只允许探测明确绑定的一个节点。更换目标先暂停，再用总开关明确保存本订阅下次启动目标，重新预览并启动。取消全部探测同时取消当前订阅绑定；受管 AI 新连接将拒绝，其他订阅不处理、不注入分组或 REJECT。
5. 撤销检测规则只移除新增的端点条件，原 AI 规则继续工作。停用并交还 Clash 是另一个操作，按原有逐订阅归属账本撤销稳航自己的所有内容。

## 订阅切换与持久化

授权来自本地 `subscription-authorization.json` 的精确 UID。A 为授权订阅时，切换 B 后所有自动写入、探测、维护、导入与旧记录重放均跳过；不注入 AI/HK 分组，不设置 REJECT。刷新、重启、订阅名称相同或已有历史恢复记录均不能代替授权。返回 A 后才恢复按原固定目标与规则偏好工作。

请求发出、配置校验后的提交、各文件写入、内核重载与恢复之前再次核对 UID。事务期间离开授权订阅时，不向当前订阅重载旧运行配置；仅恢复原事务拥有的扩展文件，并提示回原订阅核对。外部进程切换无法与稳航形成跨进程原子事务，因此不承诺切换的每一瞬间或既有会话始终固定。

授权订阅的规则保存在其扩展文件中，稳航停止后重载该订阅可继续采用；非授权订阅始终保持其原生分流。Clash 切换加载窗口、其他软件改写和旧连接仍须另核对。普通国内应用按原订阅处理。授权文件的真实 UID 只留本机，本地交付资料单独保存；通用源码和安装包不携带身份。安装器保留已有授权文件，缺失时不会自动按名称或当前订阅认领。

隔离真实内核加载持久规则可以证明 Mihomo 的执行边界；它不能代替真实 Clash Verge GUI 切换和扩展合成过程的验收。未做真实 GUI 验证时明确记为未测，不据此报告“始终生效”。

## 探测证据与 IP 证据

探测勾选在保存前属于草稿，页面标出“选择未保存”；离开表单阅读说明后，定时刷新仍保留草稿和列表滚动位置。保存成功才替换已生效范围，操作失败或取消预览不会丢弃草稿。

每次请求执行前重新检查明确选择和当前订阅。取消或改选使排队任务失效；已发出的请求允许自然完成，完成回调不为取消节点增加新统计。空集不发出稳航延迟检测，连用于故障归因的 DIRECT 对照也不发出。非空范围下可发出本地网络 DIRECT 对照，它不是备用节点探测。

未探测显示“未探测”，不增加失败；取消后旧结果标为历史并保留原时间。Clash 内核或订阅自带的 URLTest、Fallback、provider health-check 不受稳航探测选择控制，不能把它们的请求数当作稳航越界或稳航已检测的证据。

设置显示 IP138、IP.cn、Cloudflare 三项实际公网 IP 核实状态。当前没有实现公网检测结果采集，三项显示未核实、未实测；不以节点名称、规则回读或路由推演填入 IP，也不声称三项一致。候选验收只请求本机合成目的地。

## 回滚

导入事务失败自动恢复；预览撤销检测规则保留已有 Claude 规则。退回旧程序前保持停止，并成套恢复配置和归属账本：旧版不理解本机单订阅授权和探测范围，不应直接带新配置恢复自动运行。发布由管理对话另行验收，本开发不触及生产启动项。
