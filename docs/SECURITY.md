# 安全与隐私

## 数据分类

| 数据 | Git | 日志 | 看板 |
|---|---|---|---|
| 源码与模板 | 允许 | 不需要 | 不显示 |
| 节点显示名称 | 允许 | 可记录 | 可显示 |
| 订阅 URL、令牌、密码 | 禁止 | 禁止 | 禁止 |
| 节点服务器地址 | 默认禁止 | 默认禁止 | 禁止 |
| 连接目标域名 | 最小化 | 仅诊断摘要 | 默认不显示 |
| `state.json` | 禁止 | 不复制 | 经脱敏后展示 |

## 控制面

- 看板只绑定 `127.0.0.1`。
- 第一版只允许 GET。
- 不提供网页端节点切换、服务停止或状态清空。
- 不加载外部脚本、字体或 CDN。
- 使用 CSP、`no-store`、`nosniff` 和 `no-referrer`。
- `/api/status`、`/api/v1/status`、固定 fixture 和结构化事件只允许字段白名单；禁止
  订阅 URL、令牌、凭据、密码和服务器地址，即使这些字段意外进入持久状态也不得投影。
- 节点 UI ID 只使用代理组名与显示名称的 SHA-256 稳定摘要；改名生成新 ID，不继承旧历史。
- 动态候选事件只发布稳定 ID、状态、reason 和时间；策略正则和节点显示名仅在专用缓存
  视图出现，不发布订阅 URL、服务器地址或完整代理对象。
- discovery `all` 只读取名称数组；SteadyRoute 不保存 `/proxies` 中的服务器或认证字段。

## 账号与出口安全

- AI 服务登录、聊天、上传和长连接必须进入同一地区策略组。
- 普通回优使用会话粘滞，避免频繁出口跳变。
- 地区识别异常、共享滥用严重或属性不明节点应降级或隔离。
- 任何规则变化都要验证没有 DIRECT 泄漏和错误地区出口。
- 动态空组必须使用 `empty-fallback: REJECT`；内置 DIRECT/COMPATIBLE/PASS/REJECT
  名称在注册表再次过滤，不能成为节点身份。

## Git 安全

- 提交前检查敏感 URL、令牌和密钥。
- 当前仓库默认仅本地，不自动推送任何远程。
- 添加远程仓库前必须确认其可见性和历史中无敏感信息。

## 部署安全

- 发布包拒绝绝对路径和 `..` 路径，并同时验证包级与逐文件 SHA-256。
- 生产 apply 禁止跳过工作树和测试门禁，并要求版本标签匹配。
- 首次生产写入只能在交互终端二次确认。
- 生产 apply 只接受精确默认目标；非生产 apply 必须使用显式开关和受限专用根目录。
- `/`、用户主目录、源码仓库、重叠路径和混合生产路径在写入前被拒绝。
- 备份可能包含运行状态，必须保留在用户本机且沿用本机文件权限，不得提交到 Git。
- group enhancement 工具没有默认生产 profiles 路径；拒绝非同级 `profiles.yaml`、宽泛目录、
  越界 UID、符号链接、缺失绑定和非 remote current profile。备份保存在受限 profiles
  子目录，含 SHA/元数据但不复制订阅正文或凭据到日志。
