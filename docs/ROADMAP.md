# 路线图

计划按单人、本机、稳定优先执行；没有外部截止日期时，以质量门槛而不是日期决定上线。

## 已完成

- 工程治理基线：唯一源码、Git、版本、检查、文档（v0.1.0–v0.2.0）。
- 可解释状态：`/api/v1` 契约、决策状态机、结构化事件（v0.3.0）。
- 维护保护：候选自动发现、空候选 fail-closed、有界日志、状态迁移（v0.4.x）。
- 故障保护：5 秒快速通道、热备、断网 / 休眠 / 站点故障识别（v0.4.3）。
- 看板重做与安全加固（v0.4.5–v0.4.6）。
- 按国家自动锁定（v0.5.0）。
- 统一安装与迁移、设置页、可选 AI 家宽专线（v0.5.1）。
- 服务模式下的写入修复、运行核对（v0.5.2–v0.5.3）。
- 诊断信息、看板文字修正（v0.5.4）；CI 运行真实 Mihomo 内核。
- 检测与换线重做：1 秒快速通道与并发确认、5 秒全量检测、按成功恢复的暂停、30 分钟窗口评分（含慢回应）；
  稳定性回优；故障切换只断开卡住的连接；没有达标备用节点时换到能连通的最好节点；AI 专线持续偏慢时更换；
  检测记录（v0.6.0）。
- 网络抖动时的连续切换：按节点实际回应耗时起疑、风暴时等 5 秒、目标先选最近 1 分钟无失败的节点（v0.6.1）。

## 已搁置

- 免终端升级（可双击的升级文件）：它是权限最高的一段代码，出错会连修复版都装不上，而收益只是
  每个版本少粘贴一行命令。
- 看板“为什么没切”的细节：AI 专线不为速度换节点，答案总是“节点没坏”；只对其他线路有意义。

## 已被取代

- 动态候选正式接管（[#24](https://github.com/z13141557217-web/steadyroute/issues/24)）：v0.5.0 起每个周期都从分组成员
  里重新取同国家的家宽节点，订阅新增的节点自动加入并预热；`candidate_registry` 的影子模式不再
  决定选路。
